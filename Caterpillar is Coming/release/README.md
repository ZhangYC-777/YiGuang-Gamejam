# Caterpillar is Coming —— 可运行版本说明（release/README）

## 1. 运行环境
- 平台：**Windows 10 / 11（64 位）**
- 无需安装任何运行时：Unity 独立版构建已自带所需组件。
- 画面分辨率默认跟随系统/窗口设置，可在游戏内或启动时调整（如有窗口模式需求，可在 Player Settings 重新构建时修改）。

## 2. 启动方式
1. 进入 `release/Caterpillar is Coming_0906_0958/` 文件夹；
2. 双击 **`Caterpillar is Coming.exe`** 启动游戏；
3. **不要把 exe 与其旁边的 `Caterpillar is Coming_Data` 文件夹分开**，
   整个文件夹拷贝/压缩后需保持同级，否则无法运行。

> 若双击后无反应：确认已解压完整（不要直接在压缩包内运行），
> 并检查是否被杀毒软件拦截；可右键 → 属性 → “解除锁定”后重试。

## 3. 游戏简介
操控藤蔓为毛毛虫搭出一条通路：先按住鼠标左键引导藤蔓生长、
避开障碍到达终点；随后切换为控制毛毛虫，在叶子与藤蔓间跑跳前进，
安全抵达关卡终点即可进入下一关。一共 **3 个关卡**，另有主菜单。

## 4. 操作说明
| 操作 | 按键 |
| --- | --- |
| 引导藤蔓生长方向 | 按住鼠标左键并移动鼠标 |
| 毛毛虫左右移动 | A / D |
| 毛毛虫跳跃 | Space（空格） |
| 关卡内重开本关 | R |
| 通关面板 | “下一关”/“回到主菜单”按钮 |

（第一关开局场景内亦有操作引导牌提示。）
