# 素材来源与授权待核对表

以下是当前文件清点，尚未证明各项可随源码公开分发。文件名只用于定位，不作为作者、来源或授权依据。

| 工程内路径 | 目前可确认的信息 | 提交前需补充 |
| --- | --- | --- |
| `Assets/SunnyLand Artwork/` | 含美术、动画、音乐及示例场景 | 获取来源、作者、适用许可及许可原文；没有在该目录找到说明文件 |
| `Assets/Fonts/NotoSansSC-VF.ttf` | 字体文件 | 对应版本来源和随附许可原文 |
| `Assets/Audios/Pixel-Paradise-Demo.ogg` | 音频文件 | 作者、来源链接、使用及源码分发条件 |
| `Assets/Resources/Audio/Pixel-Paradise-Demo.ogg` | 同名音频的另一存放位置 | 核对来源；本次不删除或合并游戏资源 |
| `Assets/Sprites/` | 背景、角色、敌人、障碍和叶子图片 | 逐项说明自制、第三方或 AI 制作情况，以及作者和许可 |
| `Assets/Scripts/` | 游戏脚本 | 团队作者及任何借用代码的来源与许可 |
| `Packages/manifest.json`、`packages-lock.json` | 包依赖及锁定记录 | 保留相关包的原许可；不要把第三方依赖当作团队原创 |

把实际获得的额外授权文件放在 `other/licenses/`，并在表中标明对应文件。当前尚未收集这些证明文件。

根目录 license.txt 仅记录提交说明要求及待确认事项，不能替代第三方素材的原授权。
